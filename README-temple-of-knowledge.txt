THE TEMPLE OF KNOWLEDGE — CALCism Reading Portal

Files
- index.html: website interface
- styles.css: responsive styling and print rules
- app.js: catalogue records and interactive features
- temple-catalogue.json: machine-readable catalogue
- the-temple-of-knowledge-full-catalogue.csv: spreadsheet-ready catalogue
- the-temple-of-knowledge-full-features-and-book-list.md: full feature inventory and catalogue
- the-temple-of-knowledge-full-features-and-book-list.txt: plain text edition
- the-temple-of-knowledge-full-features-and-book-list.pdf: printable edition

Catalogue records: 672
Subject categories: 119

Expanded in this edition: dedicated Anarchism & labour and Feminism & queer theory tabs; more works by Proudhon, Bakunin, Kropotkin, Goldman, Malatesta, Berkman, de Cleyre, Rocker, Bookchin, Ward, Makhno, Voline and Eleanor Marx; plus feminist history, Black/intersectional and decolonial feminism, socialist/materialist feminism, queer theory, trans studies, asexuality, queer justice and abolitionist approaches. Max Stirner is included under Individualist Anarchism and Egoism, not labelled a feminist or queer theorist.

How to use
1. Keep index.html, styles.css and app.js in the same folder.
2. Open index.html in a modern browser, or upload all website files to a static host.
3. Use the tabs to navigate. Print styles reveal all tabs for Print / Save as PDF.
4. Saved titles use browser-local storage and do not sync across devices.

Limitations
- Bibliographic metadata and external access links have not all been independently verified.
- Search links do not guarantee free or lawful access to a specific edition.
- The site does not host book files; check licences and local copyright law.
- This package creation does not deploy or update any live website.
