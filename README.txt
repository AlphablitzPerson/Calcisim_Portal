How to use
1. Keep index.html, styles.css and app.js in the same folder.
2. Open index.html in a modern browser, or upload all three files together to a static host.
3. Use the tabs to navigate. Use “Print / Save as PDF” or the browser print command; print styles show all tab panels.
4. Saved titles use browser-local storage and do not sync across devices.

Important limitations
- Catalogue metadata and external links have not all been independently verified.
- Search links do not guarantee free or lawful access to a specific edition.
- The site does not host book files. Check licences and local copyright law.
- The site has not been live-deployed by this package creation step.
