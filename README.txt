The Temple of Knowledge — CALCism Reading Portal

Files: index.html, styles.css, app.js, temple-catalogue.json, complete catalogue CSV, Markdown/TXT/PDF book list. Catalogue sorting: default, title A–Z, author surname A–Z/Z–A, publication year, subject and reading level; search/filter state is retained when sorting, and CSV export follows the selected sort.

For GitHub Pages, upload/replace index.html, styles.css, app.js and catalogue/document files together in the same directory. Audio/video links are search links and do not guarantee a complete, authorised or free recording. Check source perspective, edition and copyright. Religious-movement guide distinguishes specific organisations and practices from whole religious populations. This static site has no server/database.
