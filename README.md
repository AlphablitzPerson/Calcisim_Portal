# CAPSTE v4 — Elite + Common Ground Upgrade

## What you should notice immediately
- The header says **V4 · ELITE BUILD**.
- The test mode selector includes **⭐ ELITE · 116 prompts — detailed identification**.
- Elite mode explains its extra features in the test sidebar.
- Results include provisional political/worldview emoji tags and a separate CALCism compatibility panel.
- Critical Analysis includes the BITE-informed practice review.
- Local progress uses a new `capste.v4` storage key so old prototype state does not silently mask the upgrade.

## Run it
Upload the entire `CAPSTE_v4` folder to Netlify, or publish its contents through GitHub Pages. Because the app loads JSON using `fetch`, serve it through a local/web server; opening `index.html` directly as a `file://` URL may prevent data loading.

## Modes
- Standard: 32 prompts.
- Advanced: 86 prompts.
- Elite: 86 advanced prompts plus 30 diagnostic prompts (116 total).

## Important limitations
This is a prototype, not a validated psychological or religious test. Similarity scores and political tags are heuristics, not definitive classifications. Branch-specific positions may be missing. BITE is used as a structured prompt for reviewing documented practices, not as a standalone cult detector. The CALCism profile is a user-defined reference and its comparison is illustrative. No cloud account, server, email delivery, analytics or external AI submission is implemented.
